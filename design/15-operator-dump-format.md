# 15 — OperatorDump format (v1)

A plain-text format for exchanging operators between imsrg-devel (via `tools/reference/refharness`)
and the new code, for golden data and debugging. M1 (writer in the harness) and M4 (reader/writer
in `imsrg::operator`) both implement exactly this spec. A change needs a version bump.

## Rules

* UTF-8 text, one record per line, fields separated by single spaces. Lines starting with `#` are
  comments, except the mandatory first line.
* Floating-point values use `%.17g` (round-trips doubles exactly). Integers are decimal.
* Sections appear in the order below. Readers reject unknown versions, missing sections, and
  out-of-range indices. They report the line number.
* Orbit indices refer to the `orbit` list in the file. Readers map them to their own basis by
  quantum numbers (n, l, 2j, 2tz), so the file does not rely on index conventions (even though both
  codes use the same ones, D11).
* Two-body values are **normalized, antisymmetrized, J-coupled** matrix elements
  ⟨pq; J‖V‖rs; J'⟩ with `p ≤ q`, `r ≤ s`: the values of imsrg++ `TwoBody.GetTBME_J_norm`
  (`TwoBodyME.cc:408`). Do **not** use `GetTBME_J`, which returns unnormalized values (×√2 per
  identical pair, `TwoBodyME.cc:170-176`).
  For tensor operators the value is the reduced matrix element in imsrg++'s convention (to be fixed
  when tensor operators are implemented).
* All nonzero entries are listed, both (pq, rs) and (rs, pq). Readers check Hermiticity against
  the declared spec, within 1e-12 · max|V|.

## Layout

```
# imsrg-operator-dump v1
source <free text: code name, version or git hash, date>
basis emax <int> lmax <int> hw <double>
reference <name or "custom">
norbits <N>
orbit <index> <n> <l> <2j> <2tz> <occupation>            # N lines, index 0..N-1; 2tz = -1 proton
spec particle_rank <1|2|3> rank_J <int> parity <0|1> delta_Tz <int> hermiticity <H|A|N>
zero_body <value>
one_body <count>
<a> <b> <value>                                          # count lines
two_body <count>
<p> <q> <r> <s> <J_bra> <J_ket> <value>                  # count lines; J_bra = J_ket for scalars
three_body <count | none>
<a> <b> <c> <Jab> <d> <e> <f> <Jde> <2J> <value>         # reserved for M10; a<=b<=c, d<=e<=f,
                                                         # value = imsrg++ GetME_pn(Jab,Jde,2J,a,b,c,d,e,f)
end
```

## Notes

* At emax ≤ 2 the files are small enough to commit to `tests/golden/`. Larger dumps go to
  `tests/golden/generated/` (gitignored) and are regenerated by the scripts.
* The 3B section is a plain list on canonical labels, independent of whichever IMSRG(3) layout we
  choose. Converters to and from the chosen layout are part of M10.
* A tiny Python reader (`tools/reference/opdump.py`, numpy-based) is useful for ad-hoc comparisons
  and for the brute-force m-scheme tests.
