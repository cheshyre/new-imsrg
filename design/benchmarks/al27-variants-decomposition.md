# 27Al v2 - v1 operator differences: decomposition by compat option

Lead E, weekend run 2026-11-27/30 (companion of `al27-variants.md`, section 4.3). Question: which
of the options that `run.compat = "imsrg_fork_79e9330"` switches together causes which part of
the v2 - v1 differences of the 27Al NREFT operators (up to 0.12 absolute)? Until now this was
inferred from the pattern of the differences only (al27-variants.md 4.2, first version).

## 1. Method

* **Code:** debug keys `run.compat_enable` / `run.compat_disable` (feature/al27-investigate-compat-overrides,
  2dde92b; design/16 `run.*`, design/50 section 5) switch single `CompatOptions` on top of a
  profile. Binary: frontier-hip of feature/al27-investigate-variants at 5ae2720.
* **Farms** (job 6018194, 24 nodes, 12:22, 4.9 node-hours; 24 x 136 items, 0 failed): the **v2
  Omegas** of each Hamiltonian (2 Omegas, |Omega| <= 8.0), transformed with the same 136 items as
  the earlier decomposition farm 6016893 (all 34 columns at q = 0, 150, 450, 900 MeV), in
  `$IMSRG_WORK/runs/al27/investigate/compat/<H>-<variant>/farm-native/`, directories made by
  `tools/al27/make_compat_decomp.sh` (symlinks to the v2 flow outputs, every writable path in the
  directory itself):
  * `ctl-none`: compat none (the v2 operator behaviour); `ctl-fork`: the fork bundle;
  * `only-<opt>`: none + that option; `allbut-<opt>`: the bundle without that option;
  * options: `tokyo_writer_fork_79e9330` (writer), `tensor_one_body_norm_imsrgpp` (norm,
    AL-A-Q6/D72), `tensor_no_fork_diagonal_bug` (NO diag, M15-1), `tensor_ninej_threshold_1e8`
    (9j), `tensor_fork_ph_missing_rank_phase` (ph phase, AL-F1). Not farmed: `fork_step_defaults`
    (acts on the flow only: domega; v1 vs v2 Omegas is the "flow" part below) and
    `fork_operator_file_names` (file names only).
* **Contributions** (`tools/al27/compat_decomp.py`; per element, direction v1 -> v2; missing
  elements count as 0):
  op = none - fork (operator side); X = none - only_X (fix X alone at the default point);
  X (loo) = allbut_X - fork (fix X alone at the fork point); resid = op - sum_X X
  (non-additivity); flow = fork - v1 (v1 -> v2 Omegas, both with fork behaviour); total = v2 - v1.
  Hence total = op + flow exactly when v2 = none.
* **Controls:** v2 - none = 0 and compatop - fork = 0 **exactly** for all 136 items of both
  Hamiltonians: the binary of this branch reproduces the v2 production farm (6016703) and the
  earlier compat farm (6016893) bit for bit (after the writers), so the decomposition and the
  production numbers are directly comparable.

Findings:
* **M15-1 (the missing a == b, J_bra != J_ket normal-ordering term) is the largest operator-side
  effect for every rank L >= 1**, even and odd: max |Δ| 0.10 / 0.12 (L = 2, N2LOsat / DN2LOGO),
  1.3-1.4e-2 (L = 1, 3), 1.1e-2 / 5.3e-3 (L = 4), 2.4e-3 (L = 5). It changes **only one-body
  elements**: its two-body (and zero-body) differences are exactly 0 in all 136 items of both
  Hamiltonians (per-part check with `compat_decomp.load`; scratch script, numbers in the table
  below). That is consistent with the term acting only in the final re-normal-ordering of the
  evolved operator to the core (which changes 1b only), not in the bare normal ordering.
* **AL-F1 (missing (-1)^L particle-hole phase)** acts on the odd ranks only (exactly 0 for even
  L), on one- and two-body elements (two-body larger in norm): max |Δ| 8.5e-3 / 1.1e-2 (L = 1),
  0.9-1.1e-3 (L = 3), 5.7-6.7e-4 (L = 5). For L = 1 it is comparable to M15-1 (share 0.79 / 0.86
  vs 0.62 / 0.52), for L = 3, 5 smaller (0.32-0.57 vs 0.82-0.95).
* **Additivity:** the two act together non-additively only at the 1-1.5 % level (resid <= 2.7e-4,
  odd ranks; the leave-one-out contributions equal the single ones to within the same amount),
  so the per-option contributions sum to the bundle; for even ranks the residual is the writer
  rounding (<= 8e-7).
* **The other bundle parts have no measurable effect:** the D72-vs-imsrg++ tensor one-body norm
  (AL-A-Q6) changes the BCH term count of 20 / 25 of the 136 items by 1-2 terms (up or down; all
  converged, at most 29 terms, never the 40-term cap, so no NaN norm occurred in these items) and
  the operators by <= 2.6e-12; the 9j threshold 1e-8 changes them by <= 5e-16 (round-off). The
  fork writer (7 significant digits, absolute thresholds) accounts for <= 4e-7 (N2LOsat) /
  2.6e-6 (DN2LOGO), the whole operator-side difference of the scalar columns (FM0, FPhipp0).
* **Flow side** (v1 -> v2 Omegas: domega 0.2 -> 0.1, same operator code): all of the scalar
  columns' v2 - v1 difference (<= 6.3e-3, FPhipp0p at q = 0, N2LOsat) and 2-11 % (L2) of the
  tensor columns' difference.
